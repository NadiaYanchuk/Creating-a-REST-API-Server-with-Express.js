## Ход работы

### 1. Создание проекта

Создала папку проекта и выполнила команды:

```
npm init -y
npm install express
```

### 2. Исходные данные

Массив из шести книг находится в `models/bookModel.js`, массив из четырёх авторов — в `models/authorModel.js`. Кроме данных, в моделях есть функции для работы с ними: `getAll()`, `getById()`, `create()`, `update()`, `remove()`. Контроллеры не обращаются к массивам напрямую, а вызывают эти функции.

Данные хранятся в памяти, поэтому после перезапуска сервера все изменения сбрасываются.

### 3. Основные маршруты

Маршруты описаны в папке `routes` с помощью `express.Router()` и подключены в `app.js`:

```js
app.use('/api/books', bookRoutes);
app.use('/api/authors', authorRoutes);
app.use('/api/statistics', statisticsRoutes);
```

| Метод | URL | Результат |
|-------|-----|-----------|
| GET | `/api/books` | Все книги (с фильтрацией по `genre` и `year`) |
| GET | `/api/books/search?title=node` | Поиск книги по части названия |
| GET | `/api/books/:id` | Книга по ID |
| POST | `/api/books` | Добавление новой книги |
| PATCH | `/api/books/:id` | Изменение книги |
| DELETE | `/api/books/:id` | Удаление книги |
| GET | `/api/authors` | Все авторы |
| GET | `/api/authors/:id` | Автор по ID |
| GET | `/api/authors/:id/books` | Книги выбранного автора |
| GET | `/api/statistics` | Статистика |
| любой другой URL | `{ "error": "Route not found" }` со статус-кодом 404 | |

Если книга не найдена, сервер возвращает `{ "error": "Book not found" }` и код 404. ID берётся из `req.params.id` и преобразуется в число через `Number()`, так как параметры URL приходят строками.

### 4. Добавление книги

Чтобы сервер мог читать JSON из тела запроса, подключила:

```js
app.use(express.json());
```

В контроллере данные берутся из `req.body`. Если нет хотя бы одного из полей `title`, `authorId`, `genre`, `year`, сервер возвращает код 400. При успешном добавлении возвращается созданная книга и код 201:

```js
res.status(201).json(newBook);
```

### 5. Фильтрация книг

Параметры фильтрации берутся из `req.query`. Если параметров нет, возвращаются все книги:

```
GET /api/books?genre=fantasy
GET /api/books?year=1949
GET /api/books?genre=fantasy&year=1937
```

### 6. Middleware для логирования

В `middleware/logger.js` создала middleware, который выводит в терминал метод, URL, дату и время, а затем вызывает `next()`. Он подключён через `app.use(logger)` до маршрутов, поэтому срабатывает для всех запросов:

```
GET | /api/books | 29.09.2026 19:22
POST | /api/books | 29.09.2026 19:22
DELETE | /api/books/4 | 29.09.2026 19:22
```

### 7. Обработка неизвестных маршрутов

После всех маршрутов в `app.js` стоит обработчик, который срабатывает, если ни один маршрут не подошёл:

```js
app.use((req, res) => {
    res.status(404).json({ error: 'Route not found' });
});
```

### 8. Задания

**8.1. Поиск по названию.** Маршрут `GET /api/books/search?title=node`. Название книги и текст поиска приводятся к нижнему регистру через `toLowerCase()`, поэтому поиск не зависит от регистра. Маршрут `/search` стоит выше `/:id`, иначе слово `search` было бы принято за ID.

**8.2. Статистика.** Маршрут `GET /api/statistics` возвращает:

```json
{
    "booksCount": 6,
    "authorsCount": 4,
    "genresCount": 3,
    "newestBook": { "id": 5, "title": "Clean Architecture", "authorId": 3, "genre": "programming", "year": 2017 },
    "oldestBook": { "id": 1, "title": "The Hobbit", "authorId": 1, "genre": "fantasy", "year": 1937 }
}
```

Количество жанров считаю через `Set`, который хранит только уникальные значения.

**8.3. Проверка автора.** При добавлении книги проверяю, есть ли автор с указанным `authorId`. Если автора нет, сервер возвращает код 400 и `{ "error": "Author not found" }`.

## Запуск

```
npm install
node app.js
```

Сервер запускается по адресу `http://localhost:3000`.

GET-запросы можно открыть в браузере. Для POST, PATCH и DELETE использую Postman или файл `requests.http` (расширение REST Client для VS Code).

## Коды ответов

| Код | Когда возвращается |
|-----|--------------------|
| 200 | Успешный GET, PATCH или DELETE |
| 201 | Книга успешно добавлена |
| 400 | Нет обязательного поля, не существует автор или некорректный JSON |
| 404 | Книга, автор или маршрут не найдены |

## Основные понятия

| Понятие | Назначение |
|---------|------------|
| Node.js | Среда выполнения JavaScript вне браузера |
| Express.js | Framework для Node.js, который упрощает создание сервера и маршрутов |
| MVC | Разделение проекта на модели (данные), контроллеры (логика) и маршруты |
| Router | Связывает HTTP-метод и URL с функцией контроллера |
| Controller | Обрабатывает запрос и формирует ответ |
| Model | Хранит данные и функции для работы с ними |
| Middleware | Функция, которая выполняется между запросом и ответом |
| `req.params` | Параметры из URL, например `:id` в `/api/books/2` |
| `req.query` | Параметры после `?`, например `?genre=fantasy` |
| `req.body` | Данные из тела запроса (JSON в POST и PATCH) |
